# ADR 034：3D 重建以圖紙俯視圖的圓孔校正孔位

- 日期：2026-10-11
- 狀態：採用（TASK-20261011-001）

## 背景
使用者上傳 mfg-006 立式軸承座的截圖，3D 重建後孔位和原圖紙不同。查 `data/cad/cad_84bfb1bf77464bbf`（`layout: kb`，送進模型的是知識庫三視圖）：

| 孔 | 原圖紙 | Ortho2CAD 輸出（縮放到 mm） |
|---|---|---|
| 左安裝孔 | x＝−46、Ø11、貫穿 | x＝−48.7、Ø9.5、盲孔（底部剩 1.9 mm） |
| 右安裝孔 | x＝＋46、Ø11、貫穿 | **x＝＋33.9**，切進軸承座立柱的根部 |
| 注油孔 | 頂部，z 57→72、Ø6 | **在軸承孔下方往下鑽**，z 3→28、Ø3.9 |

原因：Ortho2CAD 的輸入縮到 224×224（`max_pixels` 是訓練時的設定，ADR 003），Ø6 的孔只剩約 4 px，前視圖標示孔的點線幾乎看不到。座標是模型逐字生成的，temperature 0 使每次錯誤都一樣，重跑沒有用。調高 `max_pixels` 會偏離訓練分布。

## 決定
重建後不改模型，改用圖紙本身校正：800×800 的標準三視圖很清楚，孔可以直接量出來。

1. **偵測**（`app/cad/holes.py` `detect_holes`，主行程）
   - 俯視圖：OpenCV `HoughCircles`（`HOUGH_GRADIENT_ALT`，先放大 2 倍）找候選圓，再用線條像素以最小平方法重新擬合圓心與半徑。只收圓周 85% 以上有線條、整個落在外形內的圓，所以長孔的半圓端與尺寸數字的 0 會被排除；和外形一樣大的圓是外形。
   - 前視圖：在孔兩側（x−r、x＋r）的欄位找點線（隱藏線）。有點線才算孔（凸台在前視圖是實線，例如 mfg-002 的凸轂）；點線的上下端就是孔的深度範圍。兩側都有點線時取交集，因為一側可能和其他孔的隱藏線重疊（mfg-002 的螺栓孔貼著中心孔）。
   - 同心圓只留最小的。座標換算用 `render_ortho` 的固定版面：俯視圖中心（550, 600）、前視圖中心（550, 250），比例尺為最大外形尺寸占 270 px；俯視圖上方是 +Y。
2. **移除模型畫的垂直圓孔**（`strip_vertical_holes`，沙箱子行程，執行前處理 AST）
   - Ortho2CAD 的輸出是 DeepCAD 的「草圖＋擠出」序列。法向量是 ±Z 的草圖分兩種：只有圓的切除，整句 `solid = solid.cut(solidN)` 移除；加料草圖第 2 個以後的圓是內圈，拿掉 `.add(loopK)` 和畫圓的那行。CadQuery 的 `moveTo().circle()` 會把圓放進 workplane 共用的 pending wires，不刪畫圓那行，擠出時照樣當成內圈。
   - 只刪節點、不加新程式碼，刪完再跑一次 AST 白名單檢查。認不得的寫法原樣保留，例如知識庫標準模型的寫法。
3. **切孔**（`apply_holes`，沙箱子行程，等比縮放之後）
   - 圖紙座標依外形比例換算到模型上：模型寬度和圖紙不同時，孔仍落在相同的相對位置，例如仍在底座凸緣中間。半徑直接用圖紙的 mm。
   - 上下各多切外形高度的 3%，補點線端點的誤差（點距 4 px）。孔已經在原位時照切，不會多切掉材料。
4. **不校正的情況**：一律維持模型輸出，並在結果的 `holes.reason` 寫明原因。
   - 未收錄的圖紙、照片建檔的零件：版面不固定。
   - 俯視圖沒有孔。
   - 模型的寬、深對調。
   - 孔位上方有材料：俯視圖畫成實線圓代表從上方看得到，上方有材料表示外形對不上。這時改回原本的程式碼，模型自己畫的孔也保留。
5. **用哪張圖**：有標準模型的知識庫零件一律用它的標準三視圖偵測，照片拉正後辨識出來的也一樣，因為照片的點線常被二值化洗掉。

結果的 `result.holes`：`{status: applied|skipped, reason, detected, removed, applied}`。前端在展示區 3D 的規格欄顯示「孔位校正」，在 3D 重建頁顯示狀態標籤。

## 限制
- 只處理從上方看得到的垂直孔，也就是俯視圖的實線圓。水平孔（例如 mfg-001 立板的孔、mfg-006 的軸承孔）、從底部鑽的盲孔（俯視圖是點線圓）、斜孔都不處理。
- 沉頭孔或柱坑只保留最小的那個孔。盲孔可能多鑽外形高度的 3%。
- 外形本身錯得多時（缺少凸緣、比例差很多），孔位是依外形比例換算的，可能落在不合理的位置。只有「孔位上方有材料」這種情況會被擋下。
- `eval/cad_score.py`（離線評估）呼叫 `run_cad` 時沒有給孔位，仍是模型原始輸出。`make eval-cad` 走 `/cad/reconstruct`，所以會包含校正。
