# ADR 030：段落篩選不把「色彩分析」當成某個東西的顏色（rearrange_v3）

- 日期：2026-10-07
- 狀態：採用（`models.yaml` 的 `rearrange.prompt_version` 改為 `rearrange_v3`）

## 背景
看圖細節題「主峰右邊那道瀑布看起來是什麼顏色？」（〈谿山行旅圖〉）從 answer_v4 起一直答錯「深褐色」（正解白色）。
查段落篩選（ADR 008）前後：

| | 留下的段落 |
|---|---|
| 檢索（相似度） | 構圖 0.585（寫到「主峰右側有一道細長的瀑布」）、色彩分析 0.473、技法、落款與發現 |
| 篩選後（rearrange_v2） | **只剩色彩分析** |

篩選看到問題問「顏色」，就只留下整幅畫的主色統計（深褐、褐、黑），把寫到瀑布的段落丟掉；
回答模型只看得到「整幅畫以深褐為主」，就答成深褐色。29 題看圖題裡只有這一題這樣，其他問某個東西顏色的題目
都留下了寫到那個東西的段落（「畫面」「構圖」）。

## 決定
`rearrange_v3` 只比 v2 多一句：「『色彩分析』段落只描述整幅畫的主色比例；問的是畫中某個東西的顏色時，它幫不上忙，不要列。」
- 問整幅畫用了哪些顏色的題目（一般題 3 題、保留題 1 題）照樣留下色彩分析。
- 改回答 prompt 的做法 ADR 026 試過（「色彩分析不能當某個東西的顏色」），回答模型還是照著唯一的那段答，
  所以改在上游：不要讓它成為唯一的那段。

## 注意
- 這句只處理「色彩分析」這種整幅畫的統計段落；以後若加入其他整幅畫統計（例如構圖比例），要用同樣的方式說明。
- 看圖題只有 6＋23 題；改篩選 prompt 會影響所有問答，之後改 `rearrange_*` 也要看圖題、保留題、一般題、矛盾題一起重跑。
