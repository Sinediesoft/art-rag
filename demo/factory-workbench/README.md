# 工廠模組・工作台演示

工廠模組改版的**演示介面**，還沒有接進 `frontend/`，先給組內看方向、討論。

**打開方式：直接雙擊 `index.html`**，不用安裝、不用啟動後端。3D 要連網載入 three.js（cdnjs），沒網路時其他板塊照常。

## 想法

- **左邊是對話，右邊是四個功能板塊**：圖紙、3D、排程、庫存，全部是連接法蘭 FLG-2002 的資料。
- **依靠對話編輯右邊的畫面**：在左邊打指令，就直接改右邊對應的板塊；每次修改留一張變更卡（改前 → 改後），可以復原。
- **板塊依需求縮放**：拖曳板塊之間的縫調整大小；右上角可以聚焦、最大化、收合；上方有「四格／設計檢視／生產檢視」三種版面。板塊變小時自動精簡內容。
- **板塊之間連動**：排程改了，庫存的「在製工單完工入庫日」跟著重算。
- 右上角的太陽／月亮切換明暗（淺色沿用整合版 demo 的工廠配色）。

## 可以試的指令

| 板塊 | 指令 |
|---|---|
| 圖紙 | 圖紙標出公差、放大到中心孔、加註：調質後再精車端面、版次改成 D、看全圖 |
| 3D | 3D 切剖面、改成線框、俯視、換成發黑處理的顏色、停止旋轉 |
| 排程 | WO-2610-06 提前 1 天、WO-2610-03 改到 VMC-02、WO-2610-05 交期改成 10/20、插單 FLG-2002 30 件、只看法蘭 |
| 庫存 | 入庫 20 件、二廠調 5 件到一廠、安全庫存改成 40、不良品報廢、出貨 12 件 |
| 版面 | 聚焦排程、最大化 3D、收起庫存、恢復四格 |

下面「要改哪個板塊」可以指定對象，也可以用「排程：…」開頭。

## 資料與限制

- 圖紙、3D 模型、零件規格與庫存取自專案示範資料（`kb/parts/mfg-002.json`、`data/inventory.sqlite3`、`data/index/parts/gt/mfg-002.stl`）；**排程是演示用排的**。
- 指令用規則判斷，不經過模型；修改只存在畫面上，**不寫回系統**，重新整理就還原。正式版的寫入要走後端權限與主管核准。
