AI 助理接口（MCP）

讓 Claude 等 AI 助理透過 MCP 標準，直接查詢本系統的臺灣民間藝術知識庫（版印、交趾陶、剪黏），回答附原文出處與授權。

網站是給「人」用的介面；MCP 是給「AI 助理」用的介面。兩邊讀的是同一份知識庫 kb/artworks/。

運作方式architecture

使用者 → Claude 桌面版
用自然語言問：「團鶴版印彩紙的圖案可以商用嗎？要怎麼標示？」
↓ Claude 讀工具說明，自己決定要叫哪個工具（MCP，stdio）
server.py（MCP Server，4 個工具＋1 個資料＋1 個範本）
每次呼叫都寫進登記簿 logs/tool_calls.jsonl；找不到時回傳「下一步該做什麼」
↓
search.py（自建語意搜尋）
切段成索引卡 → bge-small-zh 向量 → 作品名／人名加分（上限 0.10）→ 門檻 0.60 擋離題 → 97% 相似去重
↓
kb/artworks/（與小組同一份資料）
23 件作品、97 張索引卡；20 件臺灣民間藝術為本模組新增
↑ 只回傳原文段落＋出處＋授權，回答由 Claude 撰寫（筆電不需跑大模型）

提供的工具tools / resource / prompt

search_passages依問題找最相關的原文段落（細節、技法、用途、匠師生平），附出處與授權
search_artworks依描述找作品，回傳候選作品與編號
get_artwork依編號取得單一作品完整資料、授權與標示文字
list_artworks列出知識庫收錄的全部作品
artworks://catalog資料：館藏清單，使用者可附進對話
tour_script範本：產生指定主題與長度的導覽稿

工具說明採「適用情境／禁忌情境與替代方案／硬性規範」格式，規定 query 要帶作品名或人名、只能根據回傳段落回答、找不到就直說。

評估結果30 題 × 2 條件，2026-10-27

同一份 30 題考卷問兩次，只差「有沒有接上 MCP」：同一個帳號、同一個模型（Sonnet 5.5 Medium）、關閉網頁搜尋、每題開新對話。題型：一般 6、冷門細節 15、知識庫沒有的 4、陷阱題 5。

接上自己的 Claude 桌面版Windows

  1. 在 integrations\art-mcp\ 依序雙擊 setup.bat（裝 Python 環境）→ build_index.bat（下載向量模型、建索引）→ self_check.bat（應為 27/27）。
  2. 把下面設定合併進 Claude 桌面版設定檔的 mcpServers（路徑換成實際位置，反斜線要寫兩個）。
  3. 從右下角系統匣完全結束 Claude 再打開，輸入框旁「＋」就看得到 art-rag。
{
  "mcpServers": {
    "art-rag": {
      "command": "C:\\dev\\art-rag\\integrations\\art-mcp\\.venv\\Scripts\\python.exe",
      "args": ["C:\\dev\\art-rag\\integrations\\art-mcp\\server.py"],
      "env": { "PYTHONUTF8": "1", "HF_HUB_OFFLINE": "1" }
    }
  }
}

技術清單stack

Model Context Protocol（mcp 2.3.0，stdio） Python 3.12・uv RAG 檢索增強生成 fastembed・BAAI/bge-small-zh-v1.5（512 維） 餘弦相似度＋關鍵字加分混合排序 相似度門檻・近重複去除 工具說明設計（tool description） 結構化日誌（JSONL） A/B 對照評估・自動計分＋人工複核 JSON Schema 資料規格（小組 validate_kb） CC 授權標示

已知限制與下一步

・長段落裡的人名會被稀釋：江清露的生卒年寫在一段講北港朝天宮屋頂的長段落裡，問「江清露的生平」時分數 0.565 沒過門檻（加上廟名可達 0.869）。下一步：把卡切得更小，或名字命中時放寬門檻。

・口語問法可能不叫工具：「我去褒忠祠拜拜看到……」這類現場描述，Claude 曾當成一般知識直接回答。下一步：工具說明加入「宮廟名、現場看到的作品」等情境。

・未做：小組網站內建聊天改走 MCP（需改權限控管）；連接模式（MCP 轉呼叫小組後端 API）待展示主機確定。
