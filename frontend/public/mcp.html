運作方式architecture

網站給「人」用，MCP 給「AI 助理」用，兩邊讀同一份知識庫 kb/artworks/。工具只找原文，回答由 Claude 撰寫，所以筆電不用跑大模型。

server.py　MCP Server：4 個工具＋1 個資料＋1 個範本；每次呼叫記進 logs/tool_calls.jsonl

手動設定進階

不想用 connect_claude.bat 時：依序執行 setup.bat → build_index.bat，再把下面設定合併進 Claude 設定檔的 mcpServers（路徑換成實際位置），從系統匣完全結束 Claude 後重開。

設定檔位置：Store 版 %LOCALAPPDATA%\Claude-Data\claude_*\claude_desktop_config.json；官網版 %APPDATA%\Claude\claude_desktop_config.json。

"art-rag": {
  "command": "C:\\dev\\art-rag\\integrations\\art-mcp\\.venv\\Scripts\\python.exe",
  "args": ["C:\\dev\\art-rag\\integrations\\art-mcp\\server.py"],
  "env": { "PYTHONUTF8": "1", "HF_HUB_OFFLINE": "1" }
}
看不到 art-rag？troubleshooting
  • Claude 要從右下角系統匣「完全結束」再打開，設定才會生效。
  • 雙擊 check_claude_config.bat：檢查設定檔有沒有寫對。
  • 雙擊 self_check.bat：模擬 Claude 連線，應為 27/27。
  • 紀錄在 integrations\art-mcp\logs\server.log，每次啟動會多一行「啟動」。
  • 資料夾路徑不能有中文（例如放在 C:\dev\art-rag）。

已知限制與下一步
  • 長段落裡的人名會被稀釋：「江清露的生平」分數 0.565 沒過門檻，加上廟名可達 0.869。下一步：切更小段，或名字命中時放寬門檻。
  • 口語現場描述可能不叫工具：「我去褒忠祠拜拜看到……」曾被當一般知識回答。下一步：工具說明加入宮廟、現場情境。
  • 未做：連接模式（MCP 轉呼叫小組後端 API）；網站內建聊天改走 MCP。
