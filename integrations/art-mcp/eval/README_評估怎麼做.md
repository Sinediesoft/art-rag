# eval/：評估用的檔案（階段 6）

> 2026-10-23 先寫好計分程式。階段 6 的完整講義會在進入階段 6 時產生，這份只說明檔案怎麼放。

## 檔案

| 檔案／資料夾 | 誰寫 | 內容 |
| --- | --- | --- |
| `baseline_questions.csv` | Claude（原流程 3-4） | 基準測試 10 題（階段 3 用） |
| `questions.csv` | **你出題**（原流程 6-1） | 評估題目。已先放入基準 10 題，你再加 20 題，湊滿 30 題 |
| `answers/A/<題號>.txt` | 你貼回答 | 條件 A（不接 MCP）的回答，一題一個檔 |
| `answers/B/<題號>.txt` | 你貼回答 | 條件 B（接上 MCP）的回答，一題一個檔 |
| `results/` | `score.bat` 自動產生 | `report.html`（圖表）、`score_summary.md`、`per_question.csv`、`tool_map_B.csv` |

`answers/` 裡的空白檔案不用自己建：雙擊一次 `score.bat`，它會照 `questions.csv` 自動建好。

## questions.csv 每一欄

| 欄位 | 怎麼填 | 例子 |
| --- | --- | --- |
| 題號 | 不重複就好 | `B01`、`Q11` |
| 類型 | 一般／冷門細節／知識庫沒有的／陷阱題 | `冷門細節` |
| 問題 | 要問 Claude 的話 | |
| 正確答案關鍵字（用｜分隔） | 回答裡**應該出現**的詞；該拒答的題可以空白 | `千里眼｜順風耳` |
| 答案出自哪一筆 | 作品編號，用來檢查出處網址對不對；好幾筆都對就用｜分隔；知識庫沒有的題空白 | `nmth-20030080677` |
| 應該用的工具（用｜分隔） | 這題 Claude 應該呼叫哪個工具；寫 `無` 表示不該用工具；空白就不計分 | `search_passages｜search_artworks` |
| 正確參數 | 工具參數裡應該出現的字，通常是作品編號；空白就不計分 | `tcmb-266892` |
| 是否應拒答 | `是` 或 `否` | `否` |

用 Excel 打開編輯時，存檔請選「CSV UTF-8（逗號分隔）」，中文才不會變亂碼。

## 兩個條件怎麼跑（重點）

**條件 A（不接 MCP）**：用 claude.ai 網頁版的**無痕對話**（不會讀記憶和過去的聊天，也不會載入電腦上的 art-rag）；關網頁搜尋；不在 Project 裡；**每題開一個新對話**；記下用的模型名稱，條件 B 用同一個。基準 10 題（B01～B10）在階段 3 已經用這個方式做過，回答就在 `answers/A/`。

**條件 B（接上 MCP）**：開回 art-rag，其他一樣。

**條件 B 一定要照題號順序做，問完一題就馬上把回答貼進檔案、存檔，再問下一題。**
因為工具呼叫紀錄只記時間，`score.py` 是用「回答檔的存檔時間」來判斷哪幾次工具呼叫屬於哪一題。
第一次計分後，對應結果會固定存在 `results/tool_map_B.csv`；之後就算改了回答檔，對應也不會亂。對錯了可以直接改這個檔。
